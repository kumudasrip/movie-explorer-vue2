# 🎬 Movie Explorer (Vue.js 2)

Movie Explorer is a simple and interactive web application built using **Vue.js 2** that allows users to search for movies and view detailed information using the **OMDb API**.

---

## 🚀 Features

- 🔍 Search movies by name  
- 🎞️ Display movie posters, titles, and release years  
- 📄 Click on a movie to view full details in a modal popup  
- ⭐ Shows genre, plot, actors, and IMDb rating  
- ⚡ Lightweight app using Vue.js via CDN 
- 📱 Fully responsive design  

---

## 🛠️ Tech Stack

- **Vue.js 2**
- **HTML5**
- **CSS3**
- **JavaScript**
- **OMDb API**

---

## ▶️ How to Run the Project

1. Download or clone the repository  
2. Ensure all files (`index.html`, `style.css`, `app.js`) are in the same folder  
3. Open `index.html` in any modern web browser  
4. Enter a movie name and click **Search**

---

## 🎨 UI & Styling

- Dark theme interface  
- Responsive grid layout for movie cards  
- Smooth hover effects  
- Scrollable modal for long content
